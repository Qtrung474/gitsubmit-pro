Cài Đặt GitHub Personal Access Token

Token giúp ứng dụng kết nối trực tiếp với tài khoản GitHub của bạn

Token chỉ lưu trong trình duyệt của bạn (LocalStorage) và gọi thẳng đến GitHub API.

Cách lấy GitHub Token chỉ mất 30 giây:

  1. Truy cập GitHub Token Settings (Mở trang này).
  2. Tại phần Note: Đặt tên gợi nhớ (ví dụ: GitSubmit Homework).
  3. Tại phần Expiration: Chọn 90 ngày hoặc No expiration.
  4. Tại phần Select scopes: Tích chọn duy nhất ô repo (Full control of private repositories).
  5. Cuộn xuống dưới cùng bấm Generate token màu xanh lá.
  6. Sao chép mã bắt đầu bằng ghp_... và dán vào ô trên!
